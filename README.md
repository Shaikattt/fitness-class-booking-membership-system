# FitnessFlow — Computing Project Website

A responsive presentation website for the **Fitness Class Booking & Membership Management System**, a Level 5 Computing Project.

## Files

- `index.html` — semantic page structure and project content
- `style.css` — responsive visual design
- `script.js` — mobile navigation interaction

## Local preview

Open `index.html` directly in a browser, or serve the folder with any local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customise

Replace the placeholder student details in the contact section of `index.html` before submission.
